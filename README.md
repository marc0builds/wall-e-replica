# WALL-E Replica

Part of [marc0builds](https://mmessa28.github.io/marc0builds/) · [Instagram](https://instagram.com/marc0builds) · [Support the build](https://buymeacoffee.com/marc0builds)

**Status: 🟡 printing parts**

A life-sized, fully 3D-printed WALL-E replica with working tracks, moving arms and a moving head.

## Base design

The build follows the open-source [chillibasket WALL-E replica](https://wired.chillibasket.com/3d-printed-wall-e/):

- Print files: [Thingiverse thing:3703555](https://www.thingiverse.com/thing:3703555)
- Build guide: [wired.chillibasket.com](https://wired.chillibasket.com/3d-printed-wall-e/)
- Code: [github.com/chillibasket/walle-replica](https://github.com/chillibasket/walle-replica) (GPL-3.0)

The original print files are **not copied** into this repo. Download them from the links above. They stay under their author's license.
